1. src/index.html
   AVANT:
   ├─ lang="en" (🔴 mauvais)
   ├─ title: "Front" (🔴 nul)
   ├─ Pas de meta description (🔴 critique)
   ├─ Pas de canonical (🔴 risque contenu dupliqué)
   └─ Pas d'Open Graph (🔴 mauvais partage réseaux)
   
   APRÈS:
   ├─ lang="fr" (✅)
   ├─ title: "Le Rétro – Bistrot Parisien à Paris 17e Arrondissement" (✅)
   ├─ Meta description: 160 caractères optimisés (✅)
   ├─ Canonical: https://leretro-paris.fr/ (✅)
   ├─ Open Graph (Facebook, LinkedIn, Twitter) (✅)
   ├─ Meta keywords (✅)
   ├─ Preconnect pour performances (✅)
   └─ Headers de sécurité (✅)

2. src/app/auth/accueil/accueil.component.html
   AVANT:
   └─ <h2>LE RETRO</h2> (❌ pas de H1)
   
   APRÈS:
   ├─ <h1>Le Rétro – Bistrot Parisien à Paris 17e</h1> (✅)
   └─ Ajout de l'adresse et horaires en texte visible (✅)

3. src/app/auth/accueil/accueil.component.ts
   AVANT:
   └─ Pas de schémas structurés
   
   APRÈS:
   ├─ Import SchemaService (✅)
   ├─ Injection dans constructor (✅)
   ├─ addRestaurantSchema() dans ngOnInit (✅)
   ├─ addOrganizationSchema() dans ngOnInit (✅)
   └─ addLocalBusinessSchema() dans ngOnInit (✅)

4. firebase.json
   AVANT:
   ├─ Cache-Control minimal
   └─ Pas de headers de sécurité
   
   APRÈS:
   ├─ Cache-Control: 31536000 pour JS/CSS (✅)
   ├─ Cache-Control: 2592000 pour images (✅)
   ├─ Cache-Control: 3600 pour HTML (✅)
   ├─ Cache-Control: 86400 pour robots.txt/sitemap (✅)
   ├─ X-Content-Type-Options: nosniff (✅)
   ├─ X-Frame-Options: SAMEORIGIN (✅)
   ├─ X-XSS-Protection: 1; mode=block (✅)
   └─ Referrer-Policy: strict-origin-when-cross-origin (✅)

                     🚨 AVANT DÉPLOIEMENT - À FAIRE
═══════════════════════════════════════════════════════════════════════════════

1. REMPLACER LE DOMAINE
   Option A (automatique):
   $ ./replace-domain.sh votre-domaine-reel.fr
   
   Option B (manuel):
   Ctrl+H (Find & Replace)
   Find: leretro-paris.fr
   Replace: votre-domaine-reel.fr
   In: src/index.html, public/robots.txt, public/sitemap.xml,
       src/app/services/schema.service.ts

2. VÉRIFIER LES COORDONNÉES (src/app/services/schema.service.ts)
   ├─ streetAddress: "2 Rue de Tocqueville" ← À vérifier
   ├─ postalCode: "75017" ← À vérifier
   ├─ telephone: "+33140189002" ← À vérifier
   ├─ latitude: 48.8765 ← À vérifier
   ├─ longitude: 2.3070 ← À vérifier
   └─ Horaires (openingHoursSpecification) ← À vérifier

3. COMPILER
   $ ng build --configuration production
   Vérifier: ✅ Build sans erreurs

4. DÉPLOYER
   $ firebase deploy
   Vérifier: ✅ Déploiement réussi

5. VÉRIFIER EN LIGNE
   $ curl https://votre-domaine.fr/robots.txt
   $ curl https://votre-domaine.fr/sitemap.xml
   $ curl https://votre-domaine.fr/
